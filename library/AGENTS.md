# Library component guidance

Follow [the root guide](../AGENTS.md),
[library guidelines](../docs/guidelines/library.md) and
[the modelling contract](../docs/library/MODELLING.md).
Run generators from this directory with headless Blender 5.2. Python helpers
outside Blender use `.venv/Scripts/python.exe`. Change generator sources first;
regenerate, validate and copy required runtime exports into `../game/`.
This folder is part of the root repository, with no separate Git branch.

# Rocket cloud material source

Generated with OpenAI built-in imagegen, opaque image generation.

Production game VFX texture, square seamless tileable grayscale height/density
map for a fully 3D rocket explosion's turbulent smoke and combustion. Fill the
entire canvas edge to edge with richly detailed overlapping rolling soot billows,
cauliflower eddies, tightly curled folds and fine turbulent wisps. Several scales:
broad billows about one fifth of the tile, medium curling ridges, fine frayed
detail. A continuous scalar material field, no isolated smoke ball or sprite
sheet. Black low density valleys, white dense rolling crests, midgrey folded
smoke. Broad tonal range, rich midtones, no clipped white, no evenly spaced bumps.
No colored fire, glow, scene, objects, ground, text, borders, grid or directional
baked lighting. Fully opaque grayscale with matching edges, organic detail for
triplanar sampling and matching normal/roughness derivation.
